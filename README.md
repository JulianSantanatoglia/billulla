## Descripción 🚀

Billulla es una aplicación web diseñada para facilitar el control de gastos, ya sea de forma individual o en pareja. Permite ingresar los ingresos de cada persona y categorizar los gastos en "gastos en común", "gastos de [Nombre Persona 1]" y "gastos de [Nombre Persona 2]".

El dashboard principal ofrece una visión clara del total de gastos de cada persona al final del mes, calculando la parte proporcional de los gastos comunes y sumándolos a los gastos individuales. ¡Ideal para llevar una gestión financiera transparente y sencilla!

## Características ✨

* **Gestión Individual y en Pareja:** Adapta la aplicación a tu situación financiera, ya sea gestionando tus gastos solo o con tu cónyuge.
* **Ingreso de Sueldos:** Permite registrar los ingresos mensuales de cada persona para tener una visión completa de la capacidad económica.
* **Categorización de Gastos:**
    * **Gastos en Común:** Ingresa aquellos gastos que son compartidos por ambas personas (alquiler, servicios, etc.).
    * **Gastos de [Nombre Persona 1]:** Registra los gastos personales de la primera persona.
    * **Gastos de [Nombre Persona 2]:** Registra los gastos personales de la segunda persona.
* **Dashboard Intuitivo:** Visualiza de forma clara el total de gastos de cada persona al final del mes. El cálculo se realiza dividiendo los gastos en común por dos y sumándolos a los gastos individuales respectivos.
* **Tecnologías Modernas:** Desarrollada con Vite para un desarrollo rápido, React para una interfaz de usuario dinámica, TypeScript para mayor seguridad y mantenibilidad del código, JavaScript para la lógica de la aplicación y Tailwind CSS para un diseño responsivo y fácil de personalizar.

## Instrucciones de Uso ⚙️

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/JulianSantanatoglia/billulla.git](https://github.com/JulianSantanatoglia/billulla.git)
    cd billulla
    ```
2.  **Instalar las dependencias:**
    ```bash
    npm install
    # o
    yarn install
    # o
    pnpm install
    ```
3.  **Iniciar la aplicación en modo desarrollo:**
    ```bash
    npm run dev
    # o
    yarn dev
    # o
    pnpm dev
    ```
    Abre tu navegador en la URL que se muestre (normalmente `http://localhost:5173`).
